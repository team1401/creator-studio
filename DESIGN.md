# Studio visual direction

Brian checks a production decision on his phone in daylight, then returns to a larger workspace for detailed briefs. Use a light neutral workspace with a darker warm navigation rail, restrained clay action accent, and ruled production lists. Native system sans typography, 16px body, fixed 32px page heading. No stock imagery is needed: no character has been chosen, so invented portraits would confuse real and example work. Empty states describe the next concrete action.

OKLCH tinted neutral tokens, warm near-white panels, generous section rhythm, subtle full borders. Forms expand inline rather than modal-first. Desktop navigation rail becomes horizontally scrollable navigation on phones. Touch controls minimum 44px. Focus visible. Status chips include words, not just color. No animated layout or decorative motion. Formal contrast and assistive technology audit remain a review task.
